Built-in MCP server

Ask your AI assistant to draw it

Create an API token, connect any MCP client, and have it build diagrams, data models, code walk-throughs or a whole deck. Every change lands live for everyone in the project — and can be undone.

  1. (Account → API tokens).
  2. Add the hosted server to .mcp.json at your project root, with your token:
{{ mcpConfig }}

Or add it from the Claude Code CLI:

{{ mcpCommand }}

Restart your client and check it's connected. Keep .mcp.json out of git; it holds your token.
